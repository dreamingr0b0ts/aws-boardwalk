What this plank proves

  • RAG done cheaply: Titan v2 embeddings + in-Lambda cosine retrieval over an S3 vector index. No vector database, $0 idle.
  • Grounded answers: Claude Haiku 4.5 on Amazon Bedrock, constrained to cited passages with prompt guardrails and a confidence score from retrieval similarity.
  • Retrieval under glass: every answer opens to show the exact passages the cosine search surfaced, their similarity scores, which ones the answer cited, and what the answer cost to generate, down to the token.
  • A free tier that cannot be abused: visitors get 5 questions a day from a curated library; nothing a stranger types ever reaches a model, and visitor traffic draws from its own small daily pool inside the global budget, so worst-case spend is unchanged.
  • Cost containment in depth: typed questions sit behind a Cognito JWT gate (no self-signup), with API-edge throttling, per-caller daily caps, and a global daily kill switch that bounds worst-case spend even if a credential leaks.
  • Swappable corpus: point it at any domain's documents (building codes, HR policy, grant guidelines) with one sync + re-index command.
  • Audit & feedback loop: every exchange logged with token counts and latency; thumbs up/down feedback captured for review.

All infrastructure is Terraform in the public aws-boardwalk repo. Back to the Demo Hub.
