File 03 · Evidence

What this plank proves

  • Document automation end to end: S3 event → EventBridge → Step Functions orchestration with per-stage failure handling. Every document carries its own step-by-step timeline as evidence.
  • OCR & form intelligence, under glass: Textract asynchronous FORMS analysis turns scans into text plus labeled key/value pairs with confidence scores, and the page geometry is kept: hover any extracted field and see the exact spot on the original it was read from.
  • NLP & governance: Comprehend entity extraction feeds the facet index, and PII detection is mapped back onto the page as a redaction exhibit: the same black-bar pass a records office runs before releasing a document under an open-records request.
  • AI classification: Claude Haiku on Bedrock assigns a document type, title, summary, and primary date: the metadata a records clerk would otherwise key in by hand.
  • Cost transparency: every document carries an itemized processing receipt: Textract pages, Comprehend units, and Bedrock tokens, priced to the fraction of a cent.
  • Cost containment in depth: the anonymous tier is fenced per visitor (5/day by hashed IP) and by its own daily pool, both counting into the same global kill switch as the credentialed tier, so opening it moved the worst-case day by zero pages. Size and page caps are enforced before OCR starts, self-signup is disabled, and anonymous documents stay out of the public index and purge within 24 hours.

All infrastructure is Terraform in the public aws-boardwalk repo. Back to the Demo Hub.
